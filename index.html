How extraction works: Values are pulled from tables first (label–value pairs and column layout), then from free text as a fallback. “Insured Person(s) Age” is read from the AGE column and joined with commas. If a field can’t be confidently found it is left blank so you can spot-check it.
Runs entirely in your browser — no files are uploaded to any server.
